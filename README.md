# 🌌 Cosmic Wave для Яндекс Музыки

**Cosmic Wave** — это легковесное расширение для браузеров на базе Chromium (Google Chrome, Яндекс Браузер, Edge), которое полностью преобразует интерфейс веб-версии Яндекс Музыки. Оно избавляет плеер от визуального шума и превращает его в стильный, минималистичный хаб с живым видеофоном.

## ✨ Главные особенности

*   🎥 **Живой видеофон:** Заменяет стандартные градиенты на полноэкранное зацикленное видео (поддерживаются форматы `.mp4` и `.webm`). Идеально для космоса, абстракций или лоу-фай анимаций.
*   🤍 **Монохромный минимализм:** Фирменный желтый цвет Яндекса перекрашен в чистый белый для строгого и элегантного вида. Логотип Яндекса скрыт.
*   🧹 **Тотальная очистка интерфейса:** Скрыты отвлекающие элементы:
    *   AI-подсказки и генеративные бейджи;
    *   Колесо рекомендаций;
    *   Лишние пункты меню (Концерты, Подкасты, Плюс и т.д.);
    *   Значок возрастного ограничения (18+ / Explicit).
*   ⚡ **Глубокая оптимизация (GPU Acceleration):** Отрисовка тяжелого видеофона перенесена на видеокарту. Встроенная функция «умной паузы» автоматически останавливает фоновое видео, когда вы переключаетесь на другую вкладку, снижая нагрузку на процессор до 0%.

## 🛠 Установка

Так как расширение находится на стадии разработки, его нужно установить в режиме разработчика:

1. Скачайте архив с расширением (например, `CosmicWaveЯндексМузыка.zip`) и распакуйте его в любую удобную папку.
2. В эту же папку поместите ваш видеофайл и назовите его `background.mp4` или `background.webm`. *(Рекомендуется использовать видео в разрешении 1080p и размером до 15 МБ для максимальной плавности).*
3. Откройте браузер и перейдите по адресу `chrome://extensions/` (или `browser://extensions/` для Яндекс Браузера).
4. В правом верхнем углу включите переключатель **«Режим разработчика»**.
5. Нажмите кнопку **«Загрузить распакованное расширение»** и выберите папку, в которую вы извлекли файлы.
6. Откройте сайт [Яндекс Музыки](https://music.yandex.ru) и нажмите `Ctrl + F5` для жесткой перезагрузки кэша.

## 🎨 Кастомизация

Вы можете в любой момент изменить фоновое видео. Для этого:
1. Замените файл `background.mp4` (или `.webm`) в папке расширения на новый.
2. Перейдите в `chrome://extensions/` и нажмите кнопку **Обновить** (иконка круговой стрелки) на карточке расширения Cosmic Wave.
3. Обновите вкладку с музыкой.
